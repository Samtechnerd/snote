Features

Everything a paper notebook does,
and a few things it can't.

Built for a stylus, made with e-paper in mind, and designed to feel like the Apple apps you already know.

Stylus-first ink

Pen, marker and eraser with pressure. Palm rejection means only the pen writes, so your hand can rest on the screen.

Notebooks, folders, tabs

Coloured covers, one-level folders and browser-style tabs, so several notebooks stay open at once.

Typed pages and text boxes

Type with headings, lists, bold, italic and alignment, or drop text boxes onto a handwritten page and write over them.

Import and mark up PDFs

Bring in a PDF, name it, file it in a folder and annotate each page like any notebook.

Export to PDF

Turn any notebook into a PDF with your ink, text and imported pages together.

Colour or e-paper

Light and dark colour themes, plus a high-contrast e-paper mode with a refresh control that clears ghosting.

Sign in and sync

One account across devices. Notebooks, pages, typed text and imported PDFs follow you.

Web app

Open and write in your notebooks from any browser, including an iPad with Apple Pencil.

Page lock

One tap stops fingers from panning or zooming the page while you write.

See it

Made to look at home on a tablet.

The same look in the app and in the browser: clean surfaces, rounded controls, nothing in the way of the page.

PDF markup

Write straight on your PDFs

Import a file, choose a folder and it opens as a notebook with one page per PDF page. Sign, highlight, circle and comment.

  • Pen, marker and text on every page
  • Imported PDFs sync between devices
  • Export the marked-up result as a new PDF
E-paper mode

Built for e-ink screens

E-paper mode drops colour, shadows and animation for sharp black and white, with line widths instead of colours. A full refresh clears ghosting after a set number of edits.

  • High-contrast controls and dashed selections
  • Optional flash on page and tab changes
  • Switch to colour any time

FAQ

Questions

Is it safe to install from outside the Play Store?

The file comes straight from this site. Android only asks for permission because it isn't from the Play Store, and you can turn that permission back off after installing.

Do I need an account?

No. The app works on its own. You only sign in to sync notebooks with the web app and other devices.

Where is my data stored?

On the device. If you sign in, your notebooks, typed pages and imported PDFs are also stored in your account's cloud database so other devices can get them.

Does it work with my stylus?

It's built for an active stylus, and fingers are ignored while the pen is near. If your tablet's pen isn't detected, turn on "Finger draws" in the sidebar.

Will it work on my e-paper tablet?

That's what e-paper mode is for. It has been tested on an Android emulator; tuning on real e-ink hardware is still in progress, so expect rough edges.

Can I use the web app on an iPad?

Yes. Write with Apple Pencil and the page ignores your fingers once the pencil touches it.

How big can a PDF be?

Up to 25 MB for imports that sync between devices.
